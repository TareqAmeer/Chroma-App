§1 Typography — the main "AI-made" tell

Measured in the current file: var(--mono) is used 81×, var(--sans) 8×, with 23 text-transform:uppercase rules. Almost all UI chrome is uppercase letter-spaced monospace. That is the signature look of generated "technical" UI — and it is not what Lightroom, Capture One, Darkroom or Dehancer do. They use a neutral grotesque for labels and reserve monospace for numerals.
