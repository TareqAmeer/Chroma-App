// ── Auto-seed the colour samples from the segmented region ──────────────────────────────────── // `+ Skin` is segmentation-first (CLAUDE.md §5b): SAM has already answered "which pixels are this // person" before any colour is picked. Oklab because the whole skin path is in it // and chroma is the axis that separates skin from bright rock (§5b's table); k = 4 because the // gate holds CR_MAX_SAMPLES = 6 and the shaded/lit/pale/sheen split measured on __TM3390 is about // four clusters — enough to cover a body, with headroom for the user to shift-click more. // // ⚠️ Hue is CIRCULAR.
