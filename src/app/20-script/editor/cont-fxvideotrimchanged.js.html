} } // Capture Frame (V2): exports the CURRENTLY DISPLAYED frame through the exact same full-res // still export path a photo uses (processToCanvas → toBlob) — the video already owns its own // full-res source canvas (it.img, kept current by fxVideoSeekTo), so this is just "export it // like a photo, once." getPixels() inside processToCanvas is fine here: it's a single still, // not the per-frame-in-a-loop pattern the video export path itself must avoid. async function fxVideoCaptureFrame(){ const it=curItem();
