// ── CHR-289 retinex-style dynamic-range compression core (pure; NOT wired to any control yet) ───── // Multiscale illumination estimate in the spirit of Jobson, Rahman & Woodell's MSR (IEEE TIP 1997), // but each scale's surround is an EDGE-AWARE base layer: a self-guided filter (He, Sun & Tang, // TPAMI 2013) on log luminance, L = mean_k GF_rk(log(Y+eps)), radius r_k = round(sigma_k). A plain // Gaussian surround smears a bright edge into its dark neighbour, so the dark side near the edge is // under-lifted (the MSR halo); the guided filter keeps the step in the base, so the gain stays flat // up to the edge. gfEps (log-domain variance, default 0.04) sets which steps count as edges: // smaller keeps more edges. Instead of MSRCR's output stretch (an image-global gain/offset that // would differ per tile), the illumination is compressed about a caller-supplied ANCHOR (a // whole-image statistic, computed once, never per tile): // d = L - log anchor; log gain = -(d<0 ? shadows : highlights) * d, clamped to +-log(maxGain). // The caller multiplies scene-linear RGB by the gain (hue-preserving). Strengths are 0..1; both 0 // returns null so the neutral path does no work. Box sums are direct (fixed summation order) with // clamp-to-edge; the guided filter is two box stages, so its reach is 2r and a tile carrying // drcRetinexHalo(sigmas) = 2*max r pixels of halo on every side reproduces the whole-image gain // exactly in its interior.
