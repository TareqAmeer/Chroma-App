# Chromasmith v1.2.10 — build 13

- Fixes iOS release compilation while retaining iOS 15 support. Photos source edits use the legacy JPEG output on iOS 15–16, and the supported-format path on iOS 17+. Non-JPEG source adjustments on older iOS return a recoverable error before committing changes.
- Includes v1.2.9's Android fix: exports survive uninstall in shared Pictures/Chromasmith (videos in Movies/Chromasmith). Install over the existing app and open it to finish migration before uninstalling.

Cause: v1.2.9's PhotoPairPlugin used iOS 17-only APIs without availability guards. The app's deployment target is iOS 15. Apple documents JPEG content for the legacy renderedContentURL: https://developer.apple.com/documentation/photos/phcontenteditingoutput/renderedcontenturl.

Actual Xcode Release compilation and IPA packaging will be checked in CI before declaring the iOS release available.
