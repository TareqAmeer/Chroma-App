Editor panel components — current vs proposed

Six components the nine undesigned tool panels need, which the Editor wireframe does not have yet. Left is the app exactly as it ships today, with its own CSS and token values. Right is the proposal, built from the wireframe's existing component CSS and the design system's tokens, so it sits in the same system as the already-designed Looks and Adjust panels.

Approve or redirect this sheet before any panel is drawn. The section switch alone appears in 19 of the app's 22 tool sections — settling it once here is what stops it being invented nine different ways.

  • KeptThe switch itself, and the rule that an off section is dimmed, not hidden — so you can see what a section offers before enabling it, and touching any control turns it on. That behaviour was hard-won (CLAUDE.md §3b) and is not up for redesign.
  • MovedThe section title becomes the panel's .fieldlabel eyebrow instead of a bespoke .fx-ctrl-title. In a tabbed panel the tab already names the tool, so a second full-weight title competes with it.
  • NewEvery slider gains a live value readout via .sr-top/.sr-val. The app currently shows the number only in some sections; the wireframe's Adjust panel shows it on all of them.
  • KeptAccent colour. The app's --acc is already #61a0af, the same Mist Blue as the design system's --primary-on-dark — the accent swap has already happened, so this is not a colour change.

How the wheels work

Drag a wheel off-centre to tint that tonal region. The matching brightness slider is independent of the tint. Double-click a wheel to reset it.

  • KeptThree wheels side by side in shadow → midtone → highlight order. That is the standard grading layout and matches every other tool users come from.
  • MovedThe three brightness sliders move out from under their wheels into normal .slider-rows below. Under the wheels they are ~90px wide — too short to set a value precisely — and they are the only sliders in the app with no readable label or value.
  • MergedThe separate 9px numeric readout merges into .sr-val, so wheel brightness reads like every other slider in the panel.
  • DemotedThe three-line hint becomes a collapsed How the wheels work disclosure. It is a one-time explanation currently holding permanent space above the controls it explains.
  • MovedTechnical names (Lift/Gamma/Gain) drop to a muted second line so the plain-language name leads.

About noise reduction

Luminance NR softens grain. Colour NR removes chroma blotches. Both run before sharpening in the pipeline.

  • NewTwo forms instead of one: a short inline caption for a single actionable sentence, and a collapsed disclosure for anything longer. Today every hint is the same block of prose regardless of length or usefulness.
  • MovedThe caption sits below the controls. Above them it delays reaching the thing you opened the panel for.
  • KeptMuted colour, so a hint never competes with a control label.
  • Cut11px. Hints move to the design system's 12px --type-fine-print-size; 11px is the app's absolute floor and hints are the longest text in any panel.
