What it does

Everything you need, none of the subscription

Click any screenshot to see it full size.

113 film looks, one tap

Pick a look, then dial it back until it feels right. Kodak, Fuji, cinema stocks, instant film, black and white — and you can load any .cube you already own.

Each look is a 33³ colour lookup table applied on the GPU, so a 24-megapixel photo previews instantly.

Grain and halation that look like film

The warm glow around bright edges, the grain that gets coarser in the shadows, dust and scratches if you want them. Sized per film format, from 8mm to 65mm.

Halation is a calibrated per-channel light-scatter model measured against a reference emulation, not a blur filter. Grain is value noise fitted to real measurements.

Change one part of a photo

Brighten a face, calm a sky, even out patchy skin tone. Up to eight masks per photo, drawn by hand or selected for you.

The skin tool is contractive — it pulls tones toward a target instead of adding a constant, which is what actually evens out an uneven tan.

Full manual control when you want it

Tone curves, an eight-band colour mixer, white balance, print profiles, crop and perspective, spot healing. Undo goes all the way back.

Curves are monotone-cubic and sampled at texel centres, so a flat curve is byte-identical to no curve at all.

A photo library on the desktop

Browse a whole archive, import straight off an SD card, find people by face, or just type what you remember seeing. Runs on your machine, not in a cloud.

Face detection, face recognition and natural-language search all run locally as ONNX models. Nothing is sent anywhere.

The same app on your phone

Not a cut-down version — the same looks and the same export, in a layout built for a thumb. Add it to your home screen and it works with no signal.

Under 700px the app switches shell entirely: the photo fills the screen and tools live in a bottom sheet.

Get it

Pick your device

The browser version needs nothing installed and is the fastest way to start.

Install

  1. There is nothing to install. Open the app.
  2. The first visit downloads it once. After that it works with the internet switched off.
  3. Works in Chrome, Edge, Safari and Firefox on any computer.
Your photos never leave the machine you are sitting at. There is no server to send them to — the whole editor is one file that runs in the page.

Your first edit, in about a minute

  1. Drag a photo onto the window, or press the big +.
  2. Open Looks and tap a film stock. That is the whole look, done.
  3. Open Adjust if it needs to be brighter or warmer.
  4. Open Film to add grain and halation to taste.
  5. Hit Export. You get the full-resolution file back, straight to your downloads.

Install

  1. Download the latest Mac release and open the .dmg.
  2. Drag Chromasmith into your Applications folder.
  3. Right-click the app and choose Open, then Open again. macOS only asks this the first time.
The app is not signed with a paid Apple developer certificate, which is why macOS asks. Right-click → Open is the standard way past it. On Apple Silicon macs it runs under Rosetta — your Mac will offer to install that automatically.

What the Mac app adds

  1. The photo library — browse a whole archive, not one photo at a time.
  2. Card import — copy a shoot off an SD card, organised into folders by date.
  3. Faces and search — find a person, or describe a photo in plain words.
  4. Faster RAW — decoded natively rather than in the browser.
  5. Edit In from Lightroom — round-trip a photo and get it straight back.

The easy way

  1. Open the app in Safari.
  2. Tap Share, then Add to Home Screen.
  3. It now opens full screen like any other app, and works on a plane.
This is the recommended route, and it is what most people should do.

The native app (sideload)

  1. Go to the build page and open the newest run.
  2. Download the Chromasmith-ipa artifact and unzip it.
  3. Install the .ipa with a sideloading tool such as Flarestore, AltStore or Sideloadly.
It is not on the App Store, so the build is unsigned and you sign it yourself. You need a GitHub account to download the artifact, and builds are kept for 30 days.

Install

  1. Open the app in Chrome.
  2. Open the browser menu and choose Add to Home screen.
  3. Launch it from the icon. It works offline from then on.

On a phone it is built for one hand

  1. The photo fills the screen; tools slide up from the bottom.
  2. Swipe left and right to move between photos.
  3. Press and hold the photo to see the original.
  4. Double-tap a slider to reset it.

How it is built

For anyone who wants the engineering rather than the pitch.

A real-time colour pipeline

Five WebGL2 shader programs: grading, emission, two-pass per-channel blur and compositing. Exports are rendered in overlapping tiles with a halo wider than the blur radius, so a 100-megapixel file never exceeds a small GPU budget and the seams are mathematically invisible.

Measured, not eyeballed

The halation model was fitted numerically against a reference film emulation and is re-checked by a pass/fail scorecard. The RAW colour path is an exact transcription of Adobe’s DNG camera-profile pipeline, verified against Lightroom renders.

Tested like software, not like a demo

Every shader change is re-rendered headlessly against 18 golden images and compared byte-for-byte. Separate gates hold performance budgets, desktop layout invariants, mask storage round-trips and library scaling to five thousand files.

Offline by construction

The web app is a single 3 MB HTML file with the code, the interface and the shaders inside it. The desktop app wraps that same file in a native shell and adds local RAW decoding and on-device AI models. There is no backend anywhere in the project.
