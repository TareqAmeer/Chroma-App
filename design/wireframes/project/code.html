Active Scenario: Develop View

The primary single-photo darkroom workstation where physical film characteristics are computed onto digital RAW sensors.

Screen ID develop-master
UI Modality Split Pane + Floating Filmstrip
Primary Palette Darkroom (#1C1C1E / #224455)

Key Interactive Triggers

  • Left / Right Arrows: Rapid filmstrip switching
  • Spacebar: Quick 100% pixel loupe zoom
  • \ (Backslash): Instant before / after split preview
  • ⌘ + C: Copy current film stock grading recipe
